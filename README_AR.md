## Railway
### خدمة الإدارة
- نفس GitHub Repo.
- Start command: `npm start`
- Variable: `SITE_MODE=admin`
- Healthcheck: `/health`
- فتح رابط الخدمة يحول مباشرة إلى `/admin`، ومسار الكابتن غير متاح عليها.

### خدمة الكباتن
- نفس GitHub Repo.
- Start command: `npm start`
- Variable: `SITE_MODE=captain`
- Healthcheck: `/health`
- فتح رابط الخدمة يحول مباشرة إلى `/captain`، ومسار الإدارة غير متاح عليها.

### خدمة موحدة (اختيارية)
- `SITE_MODE=all` لفتح الواجهات من نفس الخدمة أثناء التطوير.

### Worker
- نفس المشروع.
- Start command: `npm run worker`

### المتغيرات المطلوبة
راجع `.env.example`. أهمها: `DATABASE_URL`, `JWT_SECRET`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `CAPTAIN_PASSWORD_KEY` وبيانات GREEN API عند الربط.

> ملاحظة أمنية: لا ترفع ملف `.env` الحقيقي إلى GitHub. استخدم Railway Variables للأسرار.
