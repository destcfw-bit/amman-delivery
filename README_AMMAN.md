# AMMAN DELIVERY

نظام مستقل لإدارة التوصيل والحسابات، بهوية AMMAN DELIVERY وتصميم فحمي وأحمر وفضي.

## الموجود
صفحات الكابتن والإدارة والتسجيل، المحاسبة والعمولات وإعدادات القروبات، الجرد اليومي، الحركات والتصحيحات اليدوية، تصدير الكباتن CSV قابل للفتح في Excel، الأرشيف والتسويات، إدارة الأرصدة السالبة، استقبال DropConnect ومعالجة الوسائط والصوت. أضيفت سلة الأسابيع واستعادتها وإخفاؤها عن قائمة الأرشيف، ومنع التسكير بطلب قديم. الحذف من السلة هنا إخفاء فقط ولا يمس الأرصدة. أضيف تحقق دور الإدارة على مسارات الإدارة. بيانات التحويل القديمة أزيلت.

الشعار من الصورة الأصلية المرفقة. الهوية مستقلة بواجهات إدارة وكابتن وتسجيل خاصة بـ AMMAN DELIVERY. لا توجد بيانات كباتن أو أرصدة أو أسرار من الأنظمة الأصلية.

## التشغيل على Coolify
1. اربط المستودع الحالي بـ Coolify على الفرع main، مع تطبيق مستقل.
2. إن كنت تستخدم PostgreSQL منشأة مسبقًا في Coolify، اختر Dockerfile واستخدم رابط DATABASE_URL الداخلي؛ أما Docker Compose فينشئ قاعدة مستقلة خاصة به.
3. انسخ .env.example إلى .env محليًا أو أدخل القيم في إعدادات Coolify. استخدم كلمات مرور ومفاتيح عشوائية جديدة. لا ترفع .env إلى Git.
4. DATABASE_URL لقاعدة AMMAN فقط. اترك RUN_WORKER=0 إلى أن تتحقق من جلسة DropConnect والقروب ثم فعّل المعالجة.
5. عيّن DROPCODE_API_URL وDROPCODE_API_TOKEN وDROPCODE_SESSION_ID وDROPCODE_WEBHOOK_SECRET. لا تنسخ اشتراك webhook للقروبات القديمة دون تحديد قروب AMMAN.
6. اربط الدومين المطلوب بالخدمة على المنفذ 3000. مسار / يفتح صفحة الكابتن؛ /admin للإدارة؛ /register للتسجيل.
7. من الإدارة أضف معرّف قروب AMMAN وحدد العمولة والأرضية وأرقام المشرفين وبيانات التحويل الصحيحة.
8. اربط استقبال DropConnect على https://YOUR_DOMAIN/webhooks/dropcode مع السر والجلسة الموافقين.
9. جرّب طلبًا ثم تفاعلًا وإزالته، وتأكد من الحركات والأرصدة وتشغيل الصوت من هاتف حقيقي قبل فتح النظام للجميع.

## التحقق
npm install
npm test
npm start

فحوص الصياغة ووجود الأصول نجحت. اختبارات حماية الأسبوع وسلة المحذوفات تستخدم قاعدة بيانات محاكية للردود ولا تغني عن اختبار PostgreSQL الفعلي. يلزم إجراء اختبارات كاملة على بيئة Coolify الحقيقية وعلى هاتف قبل تفعيل احتساب رسائل واتساب.
